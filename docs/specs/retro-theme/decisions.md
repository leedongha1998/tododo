# retro-theme 결정 기록

2026-09-14 프로젝트 오너와 논의해 확정한 사항. `/feature retro-theme`로 spec.md를 쓸 때 pm 에이전트가 이 파일을 먼저 읽는다.

## 배경
- ai-judge 설계를 승인하는 자리에서 오너가 "대결이니 만큼 포켓몬 대결처럼 역동적인 디자인이었으면 좋겠다"고 했다.
- 현재 앱은 Material 3 기본 위에 런처 아이콘 주황(`#E04A16`)을 시드로 한 차분한 테마다(`lib/core/theme/app_theme.dart`, `lib/features/battle/presentation/battle_chips.dart`, `docs/specs/ui-restructure/design.md`의 C4).
- ai-judge는 대결 화면 대부분(생성, 모집, 상세, 결과, 동의, 프로필)을 새로 만든다. 그래서 테마를 먼저 확정하고 ai-judge 화면을 그 위에 만든다(`docs/specs/ai-judge/decisions.md` 71번).

## 확정된 결정
1. **범위: 앱 전체를 게임풍으로.** 대결 화면뿐 아니라 할 일 목록, 프로필, 로그인까지 같은 테마를 적용한다.
2. **시각 톤: 도트·픽셀 레트로.** 초기 휴대용 게임기 대결 화면의 느낌.
3. **대결 연출: VS 매칭 인트로만 넣는다.** 매칭되거나 대결에 처음 들어갈 때 양쪽 프로필이 맞붙으며 VS가 뜨는 짧은 연출. 오너는 체력 게이지형 대결 판, 판정 결과 이펙트, 승리·패배 전체 화면 연출, 점수 변동 애니메이션을 제안받았으나 고르지 않았다(범위 밖).
4. **캐릭터 없음.** 사용자 표시 이름·이니셜과 UI 연출만으로 대결감을 낸다. 마스코트나 증거 사진을 몬스터처럼 쓰는 방식은 채택하지 않았다.

### spec.md "결정 필요" 답변 (2026-09-14 확정)
5. 픽셀 글꼴(갈무리)은 제목·버튼·탭 이름·배지·칩·숫자·VS 인트로에만 쓴다. 동의 문구, 판정 사유, 할 일 내용 같은 긴 문장은 일반 한글 글꼴.
6. 색은 런처 주황을 유지하지 않고 레트로 게임기 팔레트로 교체한다. 앱 안 아이콘과 런처 아이콘도 픽셀 스타일로 다시 만든다(`tool/generate_launcher_icons.dart`). 새 런처 아이콘과 앱 화면 색은 이어져야 한다. 스토어 스크린샷 재촬영·배너는 ai-judge 이후(TODO_BACKLOG).
7. 증거 사진은 픽셀 테두리 틀 안에 원본을 가공 없이 보여 준다.
8. VS 인트로는 대결마다 한 사람에게 한 번(참가자는 참가 직후, 모집을 올린 사람은 매칭 후 대결에 처음 들어갈 때), 약 1.5초, 화면을 누르면 건너뛴다.
9. 시스템 글꼴 크기를 따르되 화면이 무너지지 않는 상한을 둔다. 애니메이션 줄이기가 켜져 있으면 VS 인트로는 정지 화면.
10. 다크 모드 없음, 라이트 하나만.
11. 효과음·진동은 전부 범위 밖.
12. 프로필은 계정 섹션만 레트로로 정리하고, 전적·기록 영역은 테마가 자동으로 입혀지는 수준까지만(ai-judge가 다시 짠다).

## 조사 결과와 제약
- **포켓몬 IP 사용 불가.** 포켓몬 캐릭터, 로고, 폰트, 효과음, 대사("야생의 ~이 나타났다" 같은 고유 문구)와 대결 화면 레이아웃을 그대로 베끼는 것은 저작권·상표 문제가 된다. "레트로 대결 게임의 느낌"을 참고하되 고유 표현을 복제하지 않는다.
- **한글 픽셀 폰트 후보.**
  - 갈무리(Galmuri): SIL Open Font License 1.1. 앱에 번들·재배포 가능(폰트 자체 판매만 금지, 파생물은 예약 이름 사용 금지). 한글 11,172자 전체 지원. 크기별 Galmuri7/9/11/14. 닌텐도 DS 계열 폰트에서 영감을 받은 픽셀체. 출처: https://quiple.dev/font/galmuri
  - 둥근모꼴: 원본은 퍼블릭 도메인, Neo둥근모는 OFL 1.1.
  - 폰트는 `google_fonts`로 받을 수 없으므로 `assets/fonts/`에 번들하고 `pubspec.yaml`에 등록한다. OFL 라이선스 파일을 함께 넣고 앱 안 오픈소스 라이선스 화면에 노출해야 한다.
- **가독성 트레이드오프.** 오너에게 "한글 픽셀 폰트는 읽기 어렵고 사진 증거와 어울리지 않을 수 있다"고 안내한 뒤 이 톤을 선택했다. 본문·긴 문장(판정 사유, 동의 문구, 개인정보 고지)에 픽셀체를 그대로 쓸지, 제목·버튼·숫자에만 쓸지는 결정 필요.

## 아직 결정되지 않은 것 (spec.md "결정 필요"로 넘길 항목)
- 픽셀 폰트 적용 범위: 전체 텍스트 / 제목·버튼·숫자만 / 본문은 일반 한글 폰트.
- 색 팔레트: 런처 아이콘 주황을 유지할지, 레트로 게임기 팔레트로 바꿀지. 바꾸면 런처·스토어 아이콘(`tool/generate_launcher_icons.dart`)도 다시 만들어야 하는지.
- 증거 사진 표시: 픽셀 테두리 프레임 안에 원본 사진을 그대로 보여 줄지(사진 자체를 픽셀화하면 판정 근거를 알아보기 어려워진다).
- VS 인트로가 뜨는 정확한 시점: 매칭 직후 한 번 / 대결 상세에 들어갈 때마다 / 건너뛰기 가능 여부와 길이.
- 접근성: 시스템 글꼴 크기 확대 시 픽셀 폰트가 깨지는 문제, 애니메이션 줄이기 설정 존중 여부.
- 다크 모드: ui-restructure에서 범위 밖이었다. 레트로 테마에서도 라이트 하나만 둘지.
- 효과음·진동: 오너가 고르지 않았으므로 범위 밖으로 둘지 확인.

## ai-judge와의 관계
- ai-judge design.md의 화면 구조(무엇을 어디에 보여 주는가)는 그대로 유지하고, retro-theme는 "어떻게 보이는가"만 바꾼다.
- retro-theme 구현은 현재 화면(상호 승인 모델 시절 대결 상세 포함)을 새로 칠하는 게 아니라, **테마 토큰·폰트·공용 위젯(프레임, 버튼, 배지, 칩, 대화상자)·VS 인트로**를 만들고 할 일·프로필·로그인처럼 ai-judge가 건드리지 않는 화면에 적용하는 데 집중한다. ai-judge가 갈아엎을 대결 화면을 먼저 칠하면 버려진다.
